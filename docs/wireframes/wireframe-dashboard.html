P2 Halaman lanjutan (preview, detail menyusul)

Konsisten dengan sidebar di atas; hanya garis besar tiap halaman.

basic-chat

Chat playground sisi kiri: model combo picker + system prompt. Kanan: stream response + panel failover (menampilkan kandidat mana yang dipakai). Untuk uji routing tanpa CLI.

token-saver (RTK)

Toggle caveman / ponytail / headroom / system-inject + preview diff sistem-prompt sebelum/sesudah injeksi + hitungan token saved per hari.

quota

Per akun: bar kuota window reset (sprint/weekly/midnight), status aktif/cooling/disabled (§4.1), grafik pemakaian vs reset cycle.

cli-tools

Kartu per tool (Claude Code, Codex, Cursor, Cline, OpenClaw, Copilot…): "Apply" menuliskan konfigurasi endpoint/key/model ke file config tool terkait — sama persis dengan pola cli-tools 9Router.

media-providers

Sama layout Providers, tapi registry kategori audio/TTS/video (elevenlabs, cartesia, fish-audio, edge-tts). Endpoint /v1/* untuk tts/stt/image/video.

translator

Debug UI: pilih source format → target provider, kirim sample payload, tampilkan JSON request/response ter-translate + diff lossy hop. Untuk menguji direct-route pair baru (§4.1).

mitm

Toggle MITM capture (CA self-signed), tabel capture request/response per provider, export HAR. Untuk debug protokol provider baru.

pxpipe

Undecided (§10.4) — wireframe ditunda sampai protokol dipahami; kemungkinan skip v1.

skills

Undecided (§10.4) — wireframe ditunda sampai kebutuhan dikonfirmasi.
